# 🗄️ Sales Data Processing using MySQL & Jupyter Notebook

Project ini merupakan implementasi pengolahan dan analisis data penjualan toko material menggunakan MySQL dan Jupyter Notebook. Database dirancang menggunakan pendekatan basis data relasional untuk membantu pengelolaan data transaksi secara lebih terstruktur dan efisien.

## 📌 Deskripsi Project

Pada project ini dilakukan proses pengolahan data penjualan mulai dari pembuatan database, normalisasi tabel, hingga analisis data menggunakan query SQL dan Python.

Project ini bertujuan untuk menunjukkan implementasi integrasi antara MySQL dan Jupyter Notebook dalam proses pengolahan data transaksi penjualan.

## 🧩 Struktur Database

Database terdiri dari beberapa tabel utama, yaitu:

- `pelanggan`
- `produk`
- `transaksi`

Setiap tabel saling terhubung untuk mendukung proses analisis data penjualan secara relasional.

## ⚙️ Proses Pengolahan Data

Tahapan yang dilakukan dalam project ini meliputi:

1. Pembuatan database MySQL
2. Import data penjualan
3. Normalisasi tabel database
4. Pembuatan query SQL
5. Penggabungan data menggunakan JOIN
6. Analisis data transaksi
7. Integrasi database dengan Jupyter Notebook
8. Visualisasi dan eksplorasi data

## 📊 Query dan Analisis

Beberapa analisis yang dilakukan pada project ini antara lain:

- Menampilkan data transaksi berdasarkan periode tertentu
- Analisis penjualan bersih
- Pengurutan data transaksi
- Pencarian data pelanggan dan produk
- Penggabungan tabel menggunakan INNER JOIN
- Analisis data penjualan berdasarkan kriteria tertentu

## 🛠️ Tools & Technologies

- MySQL
- Jupyter Notebook
- Python
- Pandas
- SQL

## ✨ Kesimpulan

Project ini menunjukkan penerapan MySQL dan Jupyter Notebook dalam pengelolaan dan analisis data penjualan secara terstruktur. Dengan menggunakan database relasional dan query SQL, proses pengolahan data menjadi lebih efisien dan mendukung analisis data transaksi dengan lebih baik.
